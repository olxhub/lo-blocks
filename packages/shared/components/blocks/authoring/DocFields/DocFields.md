# DocFields

One block's FIELD reference — its runtime state — embeddable anywhere:
`<DocFields block="CapaProblem"/>`.

The sibling of `<DocAttributes>`, and the distinction is the useful part:
attributes are what an AUTHOR writes, fields are what the block HOLDS while a
learner uses it. A block can have many of one and none of the other.

Attributes are generated from the schema and shown on this block's Overview tab.
