# CastEditor

An editor for a cast of characters: add, remove and edit the people in a scenario,
each with an avatar, traits, a bio and stats.

Attributes are generated from the schema and shown on this block's Overview tab.

## Cast, editor, builder

Three blocks, one subject, and the difference is what each is for:

- **Cast** — makes an existing cast AVAILABLE to the content inside it
- **CastEditor** — manages the COLLECTION: who is in it
- **CharacterBuilder** — builds ONE character in depth
