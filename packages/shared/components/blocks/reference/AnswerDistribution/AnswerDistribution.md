# AnswerDistribution

Point at any input block and show the class-wide distribution of answers beside
the learner's own — the Learning Catalytics primitive.

Attributes are generated from the schema and shown on this block's Overview tab.

## `showBeforeAnswer` is a teaching decision, not a display one

Showing the distribution before a learner has answered tells them what everyone
else said, which is the thing peer instruction is trying to avoid. The default
withholds it; turning it on is a deliberate choice about the activity.

## Related blocks

- any input block — this points at one rather than collecting anything itself
